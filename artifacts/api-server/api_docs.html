API reference

Movie Catalog API

Browse catalog sections, search titles, retrieve details, and list series episodes.

Base path /api

Browse

Catalog endpoints return JSON. Most lists use a code and data envelope.

GET/trending

Trending titles. Results are in data.

GET/home?page=1

Home feed sections, usually under data.list.

GET/movies?page=1

Movie catalog sections.

GET/anime?page=1

Anime catalog sections.

GET/rankings?tabId=1

Ranked titles for the selected ranking tab.

GET/discovery

Personalized discovery feed.

Series: There is no separate /series route. Series can appear in search and catalog results; check subjectType, then use /detail/{subject_id} and /episodes/{series_id}.

Search and autocomplete

Search results are normalized into data.items.

GET/search-suggestions

Popular suggestion terms. Add ?q=Inception for query-based suggestions.

GET/search?q=Inception&page=1&subject_type=0

Full search. subject_type defaults to 0; page defaults to 1.

Search results will appear here.
Result shape: data.items is an array of title objects. Common fields include subjectId, title, cover, poster, score, releaseTime, subjectType, and runtime. The imported API uses subjectType: 1 for movies and 2 for series.
{
  "code": 0,
  "data": {
    "items": [
      {
        "subjectId": "example-id",
        "title": "Example title",
        "cover": "https://image.example/poster.jpg",
        "score": "8.8",
        "releaseTime": "2024",
        "subjectType": 2,
        "runtime": "45m"
      }
    ]
  }
}

Details and episodes

Use the subjectId from a search result.

GET/detail/{subject_id}

Title metadata, poster, description, cast, and related fields. The result is under data.

GET/episodes/{series_id}

Season and episode lists for a series. The response includes data.seasons.

Examples

Use the full base path from your API host.

Search with curl
curl -sS "https://YOUR_HOST/api/search?q=Inception&page=1&subject_type=0"
JavaScript
const response = await fetch(`${location.origin}/api/search?q=${encodeURIComponent(query)}`);
const { data } = await response.json();
console.log(data.items);
CORS: Browser origins are controlled by CORS_ORIGINS (comma-separated origins); FRONTEND_URL is also accepted. Keep the explicit origin allowlist for cookie-based sessions. For cross-origin browser requests that use sessions, send credentials: "include".
Media: This guide does not add a /watch proxy or new third-party download flow. Use media URLs only when you have permission to access and serve them.
